# DISKINDEX 

Maintain a list of files stored in your removable devices.

## Help

diskindex

    Usage: diskindex { [REGEX] | -c MOUNT_DIR | -d }
    
    Maintain a list of files stored in your removable devices.
    
    With `-c` the program stores the list of files in the removable
    media. To identify the removable media it uses it's UUID, the UUID
    is printed once the indexation finishes, it can be consulted with `-u`.
    
    With `-d` you can list the indexed removable medias, and the date
    of the indexation.
    
    Environment variables: DISKINDEX_DIR
    Configuration files: ~/.config.sh
